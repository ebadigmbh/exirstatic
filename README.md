# exirvpn
ExirVPN – Secure & Private VPN Solution

Powered by Ebadi GmbH

ExirVPN is a high-security, privacy-focused VPN solution designed to provide users with a fast, reliable, and encrypted connection. This repository contains the source code, configuration, and deployment scripts for ExirVPN, optimized for seamless use in GitHub Codespaces.
Key Features:

✅ High Security – Implements state-of-the-art encryption protocols.
✅ Privacy-Focused – No logs, complete anonymity.
✅ Fast & Reliable – Optimized for high-speed connections.
✅ Multi-Platform – Supports multiple devices and operating systems.
✅ Easy Deployment – Streamlined setup using GitHub Codespaces.
